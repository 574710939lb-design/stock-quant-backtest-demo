Stock Quant Offline Backtest Preview Kit

A compact, dependency-free Node.js kit for offline daily-bar backtesting in research and education workflows. Ships with a deterministic synthetic demo dataset, verification script and English usage notes.

Features

  • Offline only: no network data path (external fetching is blocked and verified by a test)
  • No npm dependencies, no install step (Node.js 22+ recommended)
  • 14 bundled strategy presets, e.g. ma_cross, breakout, grid, mean_reversion, momentum_rotation, trend_band
  • Configurable costs: commission, minimum fee, stamp tax, slippage; 100-share lots; optional T+1
  • Input validation (unique dates, max 2,000 bars, ≥20 simulation bars) and a dataQuality section in every report
  • JSON report: summary, risk metrics (Sharpe, Sortino, Calmar, max drawdown), trade statistics, equity curve

How it works

1. Unzip the kit and run the built-in checks (synthetic/offline checks only):

node verify.js

2. Run the synthetic demo, which writes demo-report.json:

node demo.js
# or: npm run demo   /   npm test

3. Use your own daily bars (date, open, high, low, close, volume):

const { BacktestEngine } = require('./src/autotrade/backtest');
const engine = new BacktestEngine({ initialCapital: 100000, commission: 0.0003,
  minFee: 5, stampTax: 0.001, slippage: 0.001, positionSize: 0.2, tPlusOne: true });
const report = engine.runWithBars('ma_cross', '000001', startDate, endDate, bars);
// always inspect report.error and report.dataQuality

Example only

'000001' is a placeholder six-digit code used by the bundled synthetic demo, not a recommendation. Default cost values are illustrative, not verified broker or tax rates.
